Dataset Overview

Source:
The dataset was downloaded from Kaggle.

Description:
This dataset contains transactional data including customer demographics, purchase details, and repayment status. It was used for Exploratory Data Analysis (EDA) to identify patterns, distributions, and relationships within the data.

EDA Performed:

Checked for missing values and data types

Analyzed distributions of numerical and categorical variables

Explored correlations between features

Visualized key trends and patterns
